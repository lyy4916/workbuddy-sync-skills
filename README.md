# WorkBuddy Sync Skills

This organization houses three individual WorkBuddy skills for synchronizing your WorkBuddy configuration across multiple Macs.

**Note:** ClawHub and most skill marketplaces require *one skill per repository*. Therefore, each skill is maintained in its own repo.

## Skills

| Skill | Scenario | Repository |
---|----|---|
 `workbuddy-multi-device-sync` | 2 Macs via GitHub | [GitHub](https://github.com/lyy4916/workbuddy-multi-device-sync) |
| `workbuddy-icloud-sync` | 2 Macs via iCloud Drive (no GitHub account required) | [GitHub](https://github.com/lyy4916/workbuddy-icloud-sync) |
| `workbuddy-multi-machine-sync` | 3+ Macs with machine naming and status tracking | [GitHub](https://github.com/lyy4916/workbuddy-multi-machine-sync) |


## Publish on ClawHub

1.. Visit [ClawHub](https://clawhub.ai)
2. Login with your GitHub account (lyy4916)
3. Click "Publish Skill"
/ Select "Import from GitHub"
5. Paste one of the repo URLs above
o. Fill in name, description, version (e.g. 1.0.0), and tags
7. Submit for review

Cause of copyright, repeat the process for each skill.
